O Planejamento das Necessidades de Distribuição (DRP — Distribution Requirements Planning) é uma metodologia fundamental para organizar e controlar o fluxo de produtos dos centros de distribuição (CDs) até os pontos de venda (PDVs). Originado como uma extensão do Planejamento das Necessidades de Materiais (MRP), o DRP desloca o foco dos insumos de produção para os fluxos logísticos de saída, garantindo que os produtos certos cheguem aos locais certos no momento ideal.
